KONTROLLKÜSIMUSED - praks6

1. Milline on for-tsükli põhisüntaks Bashis?
for var in list; do
    käsk
done

2. Mis vahe on lihtsate väärtuste ja jutumärkides väärtuste vahel tsüklis?
Lihtsates väärtustes käsitletakse iga tühikuga eraldatud sõna eraldi väärtusena.
Jutumärkides olev fraas (nt "Hello World") on üks väärtus, ka siis kui selles on tühikuid.

3. Mida teeb käsu asendamine (command substitution) tsüklis? Too näide.
Käsu väljund asendatakse tsükli väärtuste loendiga.
Näide:
for user in $(cut -d: -f1 /etc/passwd); do
    echo "Kasutaja: $user"
done

4. Milleks kasutatakse muutujat IFS?
IFS määrab, millise märgi järgi string sõnadeks jagatakse.
Vaikimisi on selleks tühik, tabulaator ja reavahetus.
Näide: IFS=',' jagab stringi komade kohalt.

5. Miks ei ole soovitatav kasutada for file in $(ls)? Mis on parem lahendus?
Failinimed, milles on tühikuid, jagatakse mitmeks osaks, mis tekitab vigu.
Parem on kasutada mustrit (for file in *.txt) või käsku find.

6. Kuidas näeb välja C-stiilis for-tsükkel Bashis?
for (( i=1; i<=5; i++ )); do
    echo "Loendur: $i"
done

7. Kuidas panna C-stiilis tsükkel lugema ainult paarisarve?
Alustada kahest ja suurendada igal sammul kahe võrra:
for (( i=2; i<=10; i+=2 )); do
    echo "Paarisarv: $i"
done
